- ⚠️ Renamed the RTVI UI Agent Protocol's "task" vocabulary to "job-group", aligning it with the framework's job terminology. Wire messages `ui-task` → `ui-job-group` and `ui-cancel-task` → `ui-cancel-job-group`; envelope `kind`s `task_update`/`task_completed` → `job_update`/`job_completed`; the `task_id` field → `job_id`. The paired Python models and frames are renamed to match (`UITaskMessage` → `UIJobGroupMessage`, `UICancelTaskMessage` → `UICancelJobGroupMessage`, `RTVIUITaskFrame` → `RTVIUIJobGroupFrame`, `RTVIUICancelTaskFrame` → `RTVIUICancelJobGroupFrame`, `UITask*Data` → `UIJob*Data`), as are the internal bus carriers (`BusUITask*` → `BusUIJob*`). The matching `@pipecat-ai/client-js` / `@pipecat-ai/client-react` APIs (`RTVIEvent.UITask`, `PipecatClient.cancelUITask`, `useUITasks`, `UITasksProvider`, ...) are renamed in the client SDKs.
